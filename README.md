# Global Alumina & Aluminum Asset Map — v11

## Monthly production-rate formula

The monthly production values are taken from the dedicated monthly production sheets in the original uploaded alumina-refinery and aluminum-smelter workbooks.

For each facility and month, the displayed rate is calculated exactly as:

`monthly production rate (%) = monthly production (kt) / stated annual capacity (kt/year) × 100`

There is no adjustment for the number of days in the month and the annual capacity is not divided by 12. This percentage therefore represents the month’s production as a share of the facility’s full-year capacity, following the requested convention.

## Included files

- `index.html` — self-contained interactive map.
- `monthly-production-all-years.csv` — monthly source/forecast values and the recalculated monthly percentage.
- `monthly-production-update-template-2026.csv` — 2026 monthly update sheet using the same formula.
- `facility-update-template-2026.csv` — annual facility update sheet.
